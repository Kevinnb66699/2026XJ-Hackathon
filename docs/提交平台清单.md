**项目详细介绍**（100–500 字；这段 415 字，团队 10-03 定稿，用团队原文，Claude 对照产品核过）：

```
一份英语外刊布置下去，教学往往只能按统一讲法推进。每个学生卡在哪里、理解到哪一步，教师课后很难持续看见。

知适要做的，是在不改原文的前提下，把这份差异变成可回应的信息。

学生端，提示按需出现：读得懂的地方不打扰；遇到理解障碍时，才出现刚好够用的帮助。长难句不直接给译文，而是给一把“读懂梯子”——先看清主干，再拆解难点，最后回到整句。每个学生从自己卡住的地方开始，卡住才给提示，一次答对就不多讲。

教师端，个体情况汇成班级学情视图：哪几句卡点最集中，困难在词还是句式，哪些学生需要优先关注。老师提供同一份讲义，学生各自从卡点出发，全班卡点再汇总回老师——从1到N，再回到1。

老师上传新的文章后，AI 起草提示与题目，程序逐项校验，再由老师预览、修改、确认后发布。必学内容不遗漏，提示按需出现，始终保证教师可把关。

同一份英语外刊，不再以唯一一种方式抵达。每个学生，都能以适合自己的方式完成理解。知适，让每个人知有所适。
```
