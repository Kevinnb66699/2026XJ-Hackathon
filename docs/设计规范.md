# 知适 设计规范（前端实现以此为准）

设计稿（Design 画布，7 屏）：https://claude.ai/artifact/FqRSXL3MfGxsnwXSj7d1w1

- **学生端**：问卷 → 粗读 → 词汇 → 精读（读懂梯子，学生端叫「提示」）→ 写作（表达链，选做）→ 小结
- **其他**：老师端、评委模式（展位）

## 基调

- 米白底，白色卡片，深海军蓝表示「可以点」，芥末黄表示「知识点高亮和装饰图标」，青绿表示答对，珊瑚红表示答错（10-11 队长定的配色）。
- 芥末黄、青绿、珊瑚红在白底上对比度只有 2.2–3.8:1：原色只做图标、边框、圆点和色块；要写成文字时一律用同色相的「深字」一档（白底 6.5:1 以上）。
- 不用渐变、emoji、左侧色条卡片。
- 不引用任何外部字体或 CDN（国内网络）。

## 字体

- **英文原文**（阅读区）：`Georgia, 'Times New Roman', 'Songti SC', serif`。手机 19px，行高 1.75；老师端 17px，行高 2。
- **界面**：`-apple-system, BlinkMacSystemFont, 'PingFang SC', 'Microsoft YaHei', 'Segoe UI', sans-serif`。
- **字号**：标题 18–24px，正文 14–16px，说明 12–13px。

## 组件

- **顶栏**：所有页面同一个（`SiteHeader`）。高 56px，白底，只有一行：左边 logo 加「知适」（点它回首页，每页位置相同），后面是小字页面名；右侧是小按钮（学生端是「表达本 N」胶囊按钮和「重置演示」），手机上换成短字。讲义名等说明放在页面内容顶部，不放顶栏。
- **步骤条**：问卷 · 粗读 · 词汇 · 精读 · 写作 · 小结（10-16 起，原来叫「反馈」）。当前步骤用主色加粗下划线。
- **卡片**：圆角 14px，1px 边框；焦点卡用 1.5px 主色边框。
- **按钮**：主按钮为主色底白字，圆角 12–14px，高 46–50px；次按钮为白底加边框；可点区域不小于 44px。
- **胶囊标签**（重点句、老师要求、定向、随机等）：圆角 999px，12px 字，浅底配深字。
- **注释词**：琥珀色 2px 点状下划线，点开后像查词典：词、词性、中文（有英文释义时一并显示）；先猜后看只在词汇卡上。
- **粗读点词**：琥珀浅底加 2px 虚线下划线。
- **读懂梯子**：三步直接标在原句上（第 1 步谁 → 做了什么，第 2 步拆开，第 3 步译文），一步一步点开；所有句子三步都能开，不再有锁图标（10-02 起去掉了打卡句的翻译初稿）。10-16 起学生端叫「提示」（学生说看不懂「梯子」，按钮里本来就叫「再看提示」），步骤行写成「① 初味 · 谁 → 做了什么　② 中味 · 拆开　③ 后味 · 译文」：味道词只做辅助标签，永远跟着数字和动作，打开的那一步用芥末黄深字；卡片顶上的胶囊只写「提示第 N 步」，做完的卡片上不挂味道词（免得像给句子打等级）。初味 / 中味 / 后味有先后顺序，这是有意偏离 05 评审「换成没有顺序感的说法」：提示本来就是一步一步点开的。老师端照旧叫「梯子」。
- **「给你」便签**：引用学生自己的行为和老师讲解里的原句（演示讲义是老师原话；上传文章是老师保存的讲解），不写等级。
- **图标**：内联描边 SVG，线宽 2。芝士角（三角块加两个小孔，芥末黄）是装饰图标，只放在首页页脚和学生小结，不进句子卡片（小尺寸的芥末色三角在红字旁边像警告）。

## 文案原则

- 学生端不出现「梯子」（叫「提示」），芝士味道词只用在精读提示的步骤行（tests/frontend.test.ts 锁住）。
- 学生端不出现语法术语。梯子 L1 的标签写「谁 / 做了什么」。写作页「可能写错的地方」一栏（issue #19 加的，10-03 改名，栏名不写「语法」）是唯一例外：类型用时态、主谓一致、冠词这类标签，提示里照样不用术语。
- 写作反馈只说「用得对 / 再看看用法」：只看这个表达在学生自己的句子里用得对不对，不要求和原文意思一样（10-17），用错时附「原文例句」；可能写错的地方只引学生写的几个词、标出类型、提示该检查什么；都**不给出改写后的句子**。
- 老师端可以显示结构名称（同位语从句、倒装等）。示例数据必须标明「示例数据」。
