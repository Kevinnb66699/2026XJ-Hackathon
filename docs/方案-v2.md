# 方案 v2：把讲义里的「如果」，改成「你」

> 状态：**建议稿，待团队确认**。本稿由团队原想法升级而来。过程是：竞品与教学研究调研 → 老师、学生、技术、路演四个视角评审 → 写出 v2 → 两位评审专门反驳 v2 → 按反驳意见修订。
> 文中的 S01–S29 是我们给讲义原文 29 句的编号。所有「__」都要在路演前填成真实数据。

## 1. 一句话

老师写一份讲义，每个学生读到的都是写给自己的那一份：**原文一字不改，老师的目标一个不少，变的只是每个人的「梯子」。**

产品名候选：

- **第二人称 Second Person**（推荐）：把讲义里的「如果」，改成「你」。
- **会拆的梯子 Fade**：梯子会自己拆掉，原文一字不改。
- **不一刀切 Unblanket**：同一篇外刊，不同的梯子，同一个终点。

「如果」这个词取自老师讲义的原话。Day 2 写道「如果不认识 fret 一词，很大概率可能会不理解本句话的意思」，Day 3 写道「如果对 pending 一词不够熟悉的话」。一份 PDF 只能对全班写「如果」，我们的产品让这个「如果」落到具体的人身上。

## 2. 为什么要从原想法升级

原想法的三分法是：已掌握的剔除，没掌握且容易的保留，没掌握且难的简化。方向是对的，问题出在**第三刀**。

在这份讲义里，「没掌握又难」的内容，正是老师本周的教学目标：

- pending、counterproductive 等 15 个核心词，以及 3 处倒装（so are legislators、as do two-thirds、Along with…comes）；
- Day 2 功能词填空第 10 空考 Along **with**，Day 3 第 4 空考 **pending**；
- 4 句打卡翻译（S08、S10、S17、S24）全都是长难句；
- counterproductive 从 Day 1 词表一路复现到 Day 5 写作。

如果把这些简化掉，填空、打卡、视译、写作都会失去依据。作为评委的老师很可能给出三个判断：降低标准，帮学生偷懒，跟老师抢方向盘。

研究也支持「保留原文 + 补解释」，而不是「简化」：

- **Yano, Long & Ross（1994）**：保留原文、补充解释的「详述版」，理解效果与简化版没有显著差异，而简化会删掉学习者需要学的语言项。
- **Oh（2001，韩国高中生）**：结论类似。
- **Bastani 等（PNAS 2025，高中数学课）**：学生用 GPT-4 拿答案，撤掉 AI 后成绩反而低于对照组。

| 原想法 | v2 | 为什么 |
|---|---|---|
| 难且没掌握的：自动简化 | 原文不改，叠可以逐级撤掉的台阶（L1 主干 → L2 还原语序 → L3 白话 + 中文注），最后必须在原句上答对一道微题 | 难点就是教学目标；详述和简化理解效果相当，还保住了学习机会 |
| 掌握 × 难度，两个维度 | 加第三维**老师目标**，分三级（见 §3） | 老师已经做过的筛选，我们一个都不推翻 |
| 已掌握的：剔除 | 折叠讲解和题目，附证据，每天随机抽检 | 删原句会破坏社论的论证链；随机抽检防止装会 |
| 用户画像（来源没定义） | **用老师自己的 Day 1 当诊断**，再补约 1 分钟的结构题 | 老师出的题比自报的「认识」更可靠，也不给学生多加作业 |
| 减轻学习压力 | **时间花对地方，老师看得见** | 「减负」在老师听来容易变成「降标准」 |
| 缓解老师的筛选压力 | 给老师一张**全班卡点地图** | 讲义已经选好文章、切好段；「老师会随机抽取点评」出现了 4 次，说明真正的瓶颈是看不见谁卡在哪 |

## 3. 核心规则：三维决策

**老师目标分三级**（用 `tier` 字段，不用布尔值）：

1. **必练**（不可折叠）：4 句打卡，2 段视译，15 个核心词，总结填空的 10 个答案词。
2. **精讲项**：句子分析里点名的结构点约 20 个，以及其余精讲。已掌握的可以折叠讲解，但每天至少抽检 1 道。
3. **其他**：约 54 条非核心词汇精讲（proposal、youngster、dozen 等），可以直接折叠。

**决策表**：

| | 已掌握 | 没掌握·容易 | 没掌握·难 |
|---|---|---|---|
| 必练 | 保留，不再讲解 | 原位「先猜后看」注释 | 原句不动，叠台阶，必须做原句微题 |
| 精讲项 | 折叠讲解，写明证据，随机抽检 | 原位「先猜后看」注释 | 叠台阶 |
| 其他 | 折叠 | 注释（计入每段预算） | 只注释，不出题 |

补充规则：

- **注释「先猜后看」**：先出一道二选一的语境猜义题，猜完才显示中文。每段最多 5 个注释，排序为：老师目标 > 影响题目作答 > 词频。其余生词标灰，提示「可跳过」。
- **打卡句**：交初稿之前只开放 L1。交初稿后才开放 L2 和 L3，同时保留初稿和改稿两个版本。复制到打卡平台时自动附一行标签，例如「S17 初稿独立完成，改稿用到 L2」。
- **题目不降级**：选项数量永远不减。必须先独立作答一次，第一次答错只提示段落位置，第二次答错才给短语级提示。所有改动在教师端可见。
- **强学生也有加法**：折叠后空出的位置换成 1–2 道「上探题」，素材取自老师精讲里写了但没出成题的点。例如：easy answer 暗含什么态度？用 counterproductive 写一句反驳。
- **防装会**：假词虚报 ≥ 2/8 的学生不折叠任何内容。拿不准的一律算「未掌握」。

## 4. 学生端流程

1. **诊断**：做老师的 Day 1（20 道单选 + 10 空总结填空，本来就要做）。再做约 1 分钟的补充：30 个 Day 1 没考到的精讲词，用 Yes/No 测试（含假词）；3 种结构各 2 道微题，题目难度向原文看齐。
2. **生成「我的这一周」**：从 Day 2 开始个性化。顶部显示「需要读的精讲 __ 条 → 你的 __ 条，约省 __ 分钟」。分钟数来自营地实测，不按「项」计数。
3. **读原文**：全文一字不改。必练项有锁标；难句侧边有梯子图标。
4. **关台阶**：必须在不显示台阶的原句上答对一道微题，台阶才能关闭。第一次作答的对错写回画像。
5. **渐隐**：同类结构下一次出现时，先不给台阶，直接出微题，答对记为一次「独立完成」。演示用讲义里真实存在的复现链：同位语从句 S02 the idea that → S09 worry: that → S16 the claim that（Day 3 功能词第 2 空正好考这个 that）。倒装在讲义里没有跨天复现，改用 AI 生成的同结构新句子检验迁移。

## 5. 教师端

- **锁定清单**：只读，三级分开展示，改清单就是改 JSON，不做编辑 UI。
- **卡点热力图**：分两层，各自标明数据口径。
  - 问卷层：不认识率、自报读不懂的人数，n=__，并注明「营地同龄人，非本班学生」。
  - 产品层：开到 L2 以上的人数、原句微题的独立完成率，n=__，来自同学用手机访问服务器实际操作的日志。
- **单个学生明细**：折叠了什么、依据是什么、抽检对错、打卡初稿与改稿的标签。
- **抽查方式**：「随机 + 定向」，比例由老师设置。台词是：「随机抽查照旧，另外多了两个你一定想看的人。」

## 6. MVP 范围

**做**（优先级从高到低）：

1. `article.json`：Day 2–3 的 S01–S29、词、精讲、题目、tier、L1–L3 台阶、原句微题。用 Claude Code 起草，人工校对。
2. 诊断页：Day 1 题目 + 补充题，按规则打分。
3. 决策引擎：纯函数，输入画像和 article.json，输出个人版。
4. 阅读和作业页：折叠、注释、台阶、原句微题、打卡初稿锁。
5. 并排对比：同一个阅读组件渲染两次，传入两个画像。
6. 教师页：只读，含热力图和明细。
7. 重置演示：通过 `?p=A&seed=demo` 从固定状态加载，不依赖 localStorage 里的残留。

**明确不做**：

- 通用 PDF 解析、OCR、登录、账号
- 一键整篇简化（这是产品立场）
- 运行时调用大模型
- 聊天答疑、AI 批改、录音评分
- 覆盖率仪表（外推不可信）
- 第三处以外的动画（只保留折叠和计数）

**可选**（主链路跑通后再做）：

- 一处「看得见的 AI」：为渐隐检验生成同结构的新句子，程序校验结构，人工确认后冻结。
- 窄版入库：只用 Day 3 单日讲义，让 DeepSeek 抽成固定 schema，如实展示用时。不要假装实时上传，也不要用文件哈希命中缓存。

## 7. 技术方案

- **前端**：Vite + React + TypeScript + Tailwind，单页应用，构建成纯静态文件。
- **部署**：放到队长的国内服务器上，用 Nginx 托管静态文件，同学和评委用手机扫码就能访问。不用 Vercel，它在国内经常打不开。笔记本本地再跑一份作为兜底。
- **数据**：先定死 `types.ts` 和 `article.json` 的数据契约，前端从第一天起只读静态 JSON。29 句、约 296 个词形，直接让 Claude Code 标注（词元、CEFR 级别、是否熟词僻义、中文注），队友 2 抽查最难的约 60 个。不写正则管线，也不用 wordfreq。
- **熟词僻义**：blanket、toy、shovel、air、bar、flock、reserved、pending、explicit、settled、politics 一律强制标为难。
- **大模型**：只在离线阶段使用，结果人工校对后冻结。如果要接国内模型，用 DeepSeek（兼容 OpenAI 格式），并先测 S08 和 S24 的敏感词会不会被审核拦截。OpenAI 和 Anthropic 的 API 都不对中国大陆开放。
- **同学试用**：5–10 位同学用手机访问服务器走一遍，前端记录操作日志，作为热力图的产品层数据。日志怎么回收（导出 JSON 还是加一个很小的上报接口）等服务器情况确定后再定。
- **防翻车**：
  - 冻结前 grep 构建产物里所有 `http(s)://` 外链，Google Fonts、unpkg 等全部本地化，并在场馆真实网络下用手机访问服务器完整走一遍。
  - 投影正文字号不小于 20px，对比页一次只显示一段。
  - 第二台电脑同步一份，再录一段 90 秒备份视频。
  - npm 用 npmmirror 镜像。
- **团队纪律**：一个人负责合并代码，小步提交；所有「__」统一填进 `numbers.json`，PPT 和页面都从这里读数。

## 9. 营地证据（只采 3 类）

1. **诊断问卷**（n ≥ 30）：
   - Day 1 部分题，补充的 Yes/No 测试和结构微题；
   - 第 4、5 段圈出生词；
   - 自报读不懂的句子及原因；
   - 5 个行为题：打卡时用不用翻译软件、查到第几个词放弃、哪项最耗时、各项用时、愿不愿意先做诊断。
2. **模型对照截图**：立刻跑，**不要预设结论**。如果模型保留了原意，叙事就改成两点：「它直接给整句中文，打卡变成抄」；「它不知道老师这周要教什么」。
3. **试用**：
   - 老师或导师用 10 分钟，问两个问题：「这张图你下节课怎么用？」「锁定清单漏了什么？」，记下一句原话；
   - 5–10 位同学做一人内的三步小测：先冷读 S17 试译 → 用台阶 → 再翻一句同结构新句（不给台阶）。记录第三步独立完成的比例。

另外：问卷首页写明用途和匿名方式；讲义 PDF 不进仓库。

## 11. 评委最可能问的问题

- **「外刊就是要啃难的，你们简化了学生还学什么？」**
  我们不简化。原文一字不改，必练项锁定，难句只叠会撤掉的台阶，关台阶必须在原句上答对微题。研究上，Yano 等（1994）发现详述和简化理解效果相当，但简化会删掉需要学的语言项。
- **「我把文章丢给豆包不就行了？」**
  （以实测截图为准）它不知道老师这周教什么，会把 pending 和倒装一起改掉；它直接给整句中文，打卡变成抄；它没有你的诊断，也没有老师端。
- **「和 Newsela、Diffit、LingQ 有什么区别？」**
  原文加个人生词注释这一层，LingQ 和沉浸式翻译已经做了，我们承认。我们新在两点：一是个性化的对象是**老师的讲义**（讲解收起或展开、题目先自己试还是直接给梯子；题目本身全班一样），依据是专长反转效应；二是从讲义里读出老师目标并锁定，把句法台阶接到打卡任务上。
- **「怎么知道学生真掌握了？装会怎么办？」**
  诊断用老师自己出的 Day 1 题；假词虚报高的学生不折叠任何内容；折叠不是删除，每天随机抽检；拿不准的一律算未掌握。
- **「学生另开一个窗口问豆包，你们挡得住吗？」**
  挡不住。我们只能让诚实的路径更省事：台阶就地展开，已经会的不用做。工具在老师布置的框架内使用；热力图只用来定位卡点，不用来考核学生。
- **「对好学生只做减法？」**
  不是。折叠后空出的位置换成上探题，素材来自老师的精讲。（早期方案，未实现：现在对好学生只是会的不再讲）
- **「省了多少时间？」**
  用营地实测的分钟数回答。价值主张是「时间花对地方」，省时间不是主卖点。
- **「换一份讲义还能用吗？」**
  如实回答：入库是半自动的（AI 起草 + 老师确认），一份讲义入库一次，学生端纯规则运行。（如果做了窄版入库，就现场展示用时。）
