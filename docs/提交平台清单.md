```
我们买来的一份外刊讲义里，老师讲解一句原文时写：「如果对 pending 一词不够熟悉的话，可能会造成理解困难。」可是讲义发给全班，老师只能假设「如果」你不认识这个词；谁卡在哪一句，老师看不见，只能随机抽几个人点评。

知适把这个「如果」改成「你」。原文一字不改，只改旁边的帮助：你猜错了 pending 的意思，老师那句「如果」就变成写给你的便签；一句话的题你没开梯子就第一次答对，这句老师的讲解就收起，点开还能看（老师指定的重点句除外）；难句配三步「读懂梯子」：先标出谁、做了什么，再拆开每一块，最后才给整句意思，答错或卡住时逐步打开。知适只信直接证据：猜错的词，随后点「认识」也照样当不认识。这些帮助都按固定规则给，不调用 AI。

老师这边，热力图标出全班卡在哪几句，点开看谁卡住、卡在词还是结构；点评时随机抽查照旧，另外多了两个卡得最多的人。

老师也能上传别的英文文章：AI 起草梯子和题目，程序逐条检查，老师预览、修改后发布。规划由学校按学生、按年付费，学生和老师免费用。
```
