# 展位话术（10-04 上午巡场）

> 给谁用：队友 1 主讲，队友 2 操作笔记本，队长盯网络、兜底、答技术问题。
> 手册：Demo 尽量在 **30 秒内**展示核心效果；路演时要如实说明既有基础、AI 使用情况和本次新增内容。
> 【】里是还没有的真实数据。**没填之前，跳过那一句，不要估。**

## 说话的底线

- 说「你第一次就读懂了」「先自己试」，不说「掌握了」「学会了」，也不说「已在学校使用」「AI 出的题都对」。
- 不再说「梯子不给整句中文」「打卡句交初稿前只开第一步」：现在梯子第 3 步就是整句中文意思，打卡句的翻译初稿也去掉了（10-02 队长定）。
- 老师端先看右上角：标着「示例数据」，要说「这是示例班级」，不能当成真实使用数据；显示「实时 · N 人」，要说清这 N 人是谁（朋友远程试用、今天扫码的评委），不说成某个班在用。
- 只报测过的数，并带上 n；小样本就说是小样本。
- 不贬低竞品。问到没做过、没测过的，直接说「这个我们还没做 / 还没测」。

## 四、评委可能问的 15 个问题

**1. 这和让豆包、ChatGPT 帮我简化一下有什么不同？**
简化是改原文，我们一字不改。把句子改简单，pending 这类老师点名要练的词就可能被换掉，而它正是这周要学的。我们只在你卡住的地方搭梯子，一步一步给：先找谁、做了什么，再拆开看每一块，整句中文意思放在最后一步；关梯子前要在原句上答一题。还有一点聊天工具做不到：全班卡在哪，会回到老师那里。
实测（10-02，截图在 `docs/assets/ai-compare/`）：说「帮我简化一下」，豆包、Kimi、DeepSeek 都改写了原文，DeepSeek 还给了整段中文。换成写得很细的提示词，三家都能做到不改写、只给提示，给得也不错，这一点要照实承认。区别在于：随口一问，它们就改写原文、一次全给；要只给提示，得学生自己会这么问；它们给每个人讲的都一样，不知道你卡在哪；老师也看不到。我们原文不动，按步给，卡在哪一步回到老师那里。
被追问「学生另开窗口问豆包怎么办」：挡不住，我们也不假装挡得住。我们只能让诚实的路更省事：梯子就在句子旁边，会的不用再看。

**2. LingQ、沉浸式翻译早就有「原文加生词注释」了？**
对，这一层不是我们发明的。我们适配的是**老师的讲义**：老师的讲解给谁展开、给谁收起，同类句子先让你自己试还是直接给梯子，老师的必练项锁住不动；再把全班的卡点交还给老师。它们面对一个读者，我们面对一个老师和一个班。

**3. 老师要多花多少时间？**
老师要做的是：粘贴文章（可以填必练词、打卡句、教学重点）→ 等生成 → 预览 → 发布。实测一篇 4 段 12 句的短文大约 12 秒生成完；更长的文章还没系统测过，页面上按「大约 1–2 分钟」提示。真实老师走完全程要多久，我们还没测：【老师试用计时：…分钟】。

**4. AI 起草的内容错了怎么办？**
分三层。第一，原文不经过 AI，最坏是一架梯子或一道题出错，文章本身不会错。第二，程序校验：梯子第一步必须是原句里一字不差的片段，答案在选项里、选项不重复，出处必须能在讲义原文里找到，AI 起草的梯子和题目不能有语法术语（老师讲解是老师原话，原样保留）；梯子第一步不对的，先让模型自己改一次，其余不合格的直接剔除，都写进入库报告。第三，人工校对：演示讲义里模型起草的 121 条由队友 2 逐条校对（借助 ChatGPT 复核；Claude Code 做程序体检和独立复核，分歧逐条裁定后由队长确认），改动存成人工修订文件；连同后来把题目改成英文（英文版由 Claude Code 按校对过的中文版翻译），一共 231 条，每次重新入库都自动套用，同样要过校验，不会丢。词卡上 10-02 补的内容还没过这一层：35 个词的词性和英文释义、34 道「先猜一猜」是 Claude 起草的，只经过几个独立 agent 核对，还没人工校对（15 个核心词的词性和英文释义照老师 Day 1 的核心词汇表）。梯子 10-02 换上的第 2、3 步也一样：21 架梯子的「拆开」和「整句中文意思」是 Claude 起草的，agent 和脚本核对过（每块是不是原句原话、标签对不对、有没有语法术语），还没人工校对，队长另请 ChatGPT 复核中。老师上传的文章目前只有前两层加预览，在网页里直接改是下一步。

**5. 换一篇文章行不行？**
行，现场就能试（`#/upload`）。粘贴 200–8000 个字符的英文文章，最多 12 段、60 句，生成后给学生链接和二维码。三点限制：不支持 PDF 和拍照识别，要粘贴文字；上传的文章没有老师的讲解原话，所以没有「给你」便签和讲解收起；上传文章的梯子第 2、3 步暂时还是旧版的「正常语序」「简单英文」。
被问「谁都能上传，不怕被刷吗」：不设口令，靠限次数：全站同一时间只跑一篇，每台设备每小时 5 篇，全站每天 60 篇；上传的讲义不公开列出，拿到链接才能打开。

**6. AI 用在哪里？哪些是人做的？比赛前就有什么？**
产品里 AI 只用在两处：老师那一侧起草梯子、题目和注释（组委会提供的 TokenDance，deepseek-v4-pro，一份讲义一次）；学生写作时判断表达用得对不对（deepseek-v4-flash，只判断，不改写学生的句子）。学生端「给谁看什么」全部是确定性规则，不调用 AI。
开发时，大部分代码由 Claude Code 写；方案调研和评审、界面设计稿、讲义内容的程序体检和复核、题目的英文版、词卡上大部分词的词性、英文释义和猜词题、梯子新的第 2、3 步、路演材料初稿也用了 Claude Code；队友 2 校对时用 ChatGPT 复核，梯子新的第 2、3 步队长另请 ChatGPT 复核中；海报插图用 ChatGPT 画。人做的是：产品方向和教学取舍（比如「先读懂意思，语法以后慢慢学」「材料由老师上传」「题目改成英文」），逐条校对，最后拍板。
比赛前只有想法讨论、调研和方案文档。所有代码都在 10-01 22:00 之后写，可以对照 GitHub 的提交时间。详见 `AI_USAGE.md`。

**7. 学生会不会一路点「我卡住了」？乱点「认识」呢？**
卡住就该点，我们不拦。梯子最多三步，要一步一步点开：先是谁、做了什么，再拆开每一块，第三步才是整句中文意思；一路点到底就能看到中文，我们不假装挡得住。想关梯子，要在不显示梯子的原句上答对一题。点到第几步会进老师端，一路点到底的人最容易排进「今天点评」的定向名单，等于举手。
词汇卡片里混了 1 个我们编的词。点成「认识」的话，他所有的「认识」都不作数，注释照常给。

**8. 把老师的讲解收起来，学生会不会漏学？**
收起只有一个依据：这一句你第一次就在原句上答对，而且没开梯子。收起后写明原因「你第一次就读懂了这句」，一点就能展开。打卡句的讲解不会因为答对就收起。还有一种看不到讲解的情况：这一句的题还没答，老师的讲解先不显示，免得直接看到答案；答完就出现。老师的核心词永远出现在生词卡里、永远不会被标成「可跳过」，只有你自己标了「认识」的才不加注释。讲解收起不看「你会这种句型」这类推断。唯一用到「同类句子」的是「先自己试」：同类句子你之前自己读懂过，下一句先答一题，答错立刻给梯子。

**9. 学生数据怎么处理？**
不登录、不注册、不填名字。每台设备随机生成一个编号，老师端只显示「同学 07」这样的代号。服务器是我们自己的国内服务器，存的是学习行为：点了哪些词、答题对错、梯子开到第几步，以及学生交的写作和反馈文字（早先的版本还收过打卡句的翻译初稿）。App 里开头的 3 题问卷只存在学生自己的手机上，不上传。写作检查会把学生写的句子发给组委会提供的国内模型做判断。API Key 只放在服务器上，不进仓库。老师上传的文章会发给组委会提供的国内模型（deepseek-v4-pro）起草，存在我们的服务器上，不公开列出，拿到链接才能打开；上传时带一个浏览器随机生成的设备编号，只用来限次数。

**10. 谁付钱？**
学生免费；老师个人用一个班免费，用来获客；学校按学生付费。方案里假设每生每年 99 元，外刊打卡营按期付费，假设每人每期 5 元。**这两个价格都是假设，要说清楚。**成本主要按讲义算：AI 起草一份讲义只要一次，学生越多分摊越薄；按学生算的 AI 调用只有写作检查。
被追问市场多大：方案里估算的起步市场（国际化学校的初高中学生）约 1,560 万元/年，含价格假设，口径见 `docs/方案-v3-变更清单.md` 第 4 节。需求证据：【老师 / 打卡营的意向：…】。

**11. 有证据说明有用吗？**
还没有能证明效果的实验，一篇文章也不该指望看出来，我们照实说。我们有三样东西：
一是问题是真的：9 位朋友的问卷里，6 位读不懂就整句交给翻译软件或 AI。
二是记录：一位朋友 15 分钟里，先猜后看猜错 12 个词，有 11 个点了「认识」，包括老师点名要练的 pending；精读 12 道题第一次答错，其中 10 道没开梯子，换个选项就过去了。只看最后的对勾，20 道对了 18 道，老师会以为他基本都会了。知适只信直接证据：猜错的词照样算不认识，第一次答错就算卡住，都回到老师端；看到这份记录当天，我们改成了答错先给梯子第一步。
三是怎么验证：一个班用完五天讲义，看后几天遇到同类句子、梯子先不给时，第一次就答对的比例有没有上升。这个数知适每次作答都在记。
被追问分数：三步小测冷读平均 0.67/3，用过知适后读新句平均 0.89/3（n=9），一篇文章看不出提升。这是 9 位朋友自愿远程试用，不是随机抽样，也不是对照实验；问卷要求不查词典，但远程做没人在旁边，查没查我们没法确认；问卷 9 份，后台只有 4 人留下学习记录，所以问卷里「开过梯子」的自报我们不当证据。
理论上只引一条：Yano、Long 和 Ross（1994）发现，不删难词、在文中补充解释的「详述版」，理解效果和简化版相当，而简化会删掉学习者要学的语言项。【引用前核对原文】

**12. 下一步做什么？海报上「你的卡点，变成下一届的起点」做到了吗？**
做了一半，照实说。老师端已经有「下一届的起点」（10-02 15:20 上线）：按全班卡点，列出下一版讲义该先搭梯子的句子（卡在「中」以上至少 2 人、且不少于三成），点「预览下一版」能看到学生那边的样子，这几句的梯子默认先打开第 1 步。还没做的是真正把这一版发给下一届学生，现在下一届打开的仍是原讲义。
下一步：一是老师在网页里直接改 AI 起草的内容，改完一键重新发布；二是找一个班完整用一周外刊，看撤掉梯子后学生能不能自己读懂同类句子；三是把这一篇的情况带到下一篇（现在每篇讲义分开记，换一篇不延续）。只带会增加帮助的：这一篇不认识的词，下一篇遇到直接加注释；这一篇自己读懂过的同类句子，下一篇先让你自己试，答错一次就给梯子。不带「认识的词」：熟词换一篇文章可能是另一个意思，藏错了代价大。【老师 / 学校的试用约定：…】

**13. 题目是 AI 起草的，怎么保证不同水平的学生拿到适合自己的？**
题目全班一样，这是有意的：最难的那句正是老师这周要教的，题目一降难就绕开了教学目标；全班做同一批题，老师端的卡点才能比较。按人变的是题目旁边的帮助，依据是读的时候的直接证据（点了哪个词、第一次答对没有、猜词有没有猜错）：哪些词加注释、老师的讲解收起还是展开、同类句子先让你自己试还是直接给梯子。演示讲义的题目由 AI 起草后逐条人工校对（词卡上 10-02 新加的 34 道猜词题除外，还只经过 agent 核对）；老师上传的文章只有程序校验和老师整篇预览，还不能逐题修改，而且没有老师的讲解，所以没有「讲解收起」和「给你」便签。
被追问「好学生是不是只是少讲」：对，现在是会的就不再讲，帮他省时间。给好学生多一步挑战、用开头问卷决定先给哪种帮助、把这一篇的卡点带到下一篇，都还没做，是下一步。
被追问「问卷有什么用」：现在只用来了解学生，不参与适配。证据不够时我们宁可不藏内容，藏错了代价更大。

**14. 海报上的「读懂轨迹」是什么？这算进步吗？**
老师端热力图下面就是「读懂轨迹」：同一类长难句按出现顺序排开，看每个人每一句是怎么过的：自己读懂（没开梯子、第一次就答对）、梯子到第几步第几次答对、还是答了几次还没答对。点任何一位同学的名字，能看他一个人的轨迹，标着哪几句是「先自己试」（前面同类句子自己读懂过，这一句梯子先收起、要先答题）。
不算进步，照实说：先自己试的句子三选一，蒙也可能答对；后面的句子也可能本来就更容易。轨迹只记每句是怎么过的，不说明读懂能力有变化。要看能力有没有变化，得用一周以上、撤掉梯子再测，这是下一步（见第 12 问）。

**15. 「读懂梯子」到底是什么？不就是分步提示吗？**
本质上是教学里说的「支架」：把一个熟练读者拆长句的过程分成三步，卡在哪一步，就只给到哪一步。
- 第 1 步，谁 → 做了什么：在原句里标出主干。比如 S17，谁是 such measures，做了什么是 threaten to be counterproductive。
- 第 2 步，拆开：每一块在说什么：直接在原句上批注，不另开一栏。把原句切成几块，每块上面用大白话标出它在说什么（谁 / 做了什么 / 对谁·对什么 / 什么时候·在哪里 / 为什么 / 怎么样 / 补充说明），下面再加一句简短的中文说明。不用语法术语：梯子是给卡住的学生用的，术语留在老师讲解里。
- 第 3 步，整句中文意思：整句的中文意思接在原句下面，再下面照旧列难词中文，比如 S17 的 pending 注「在等待……期间；在……得出之前」。

每开一步，都可以回到原句上再答一次题。

和翻译、简化不一样：原文一个字不动，读的始终是老师选的那句原文；整句中文也有，但放在最后一步，前面先让你自己找谁、做了什么，再拆开看；你开到第几步、卡在哪，都回到老师那里。
被追问「打卡句本来就是翻译作业，第 3 步给了中文，不就能抄了吗」：能看到，我们照实说。原来打卡句要先交翻译初稿才开第 2、3 步，我们判断它太拖慢学习，10-02 去掉了。拦是拦不住的，但一路开到第 3 步的，会进老师端、排进定向点评，等于举手。

和普通的分步提示不一样，靠的是三条规则：
- 会了就撤：同一类长句，你没开梯子、第一次就答对过，下一句就先让你自己试，答错了才给梯子。
- 开到第几步本身就是数据：只开第 1 步就答对，说明主干一找到就通了；开到第 3 步才答对，说明卡在意思上。这些都回到老师端，变成热力图和「今天点评这几个人」的依据。
- 按人给：同一句原文，有人不用梯子，有人要开到第 3 步。「原文一字不改，每个人拿到写给自己的梯子」说的就是这个。

被追问「这不是你们发明的吧」：对。支架是经典的教学方法，拆主干、把长句拆开来看也是老师讲长难句的常规做法，讲义里就有。我们做的是三件事：把它挂在老师的原句上一步一步给；按「第一次就答对」这样的直接证据决定什么时候撤；把每个人卡在哪一步交还给老师。
