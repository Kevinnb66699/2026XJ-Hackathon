# 内容总结

## 一、0基础版

**这个界面要改的核心就一句话：别让用户先读懂说明才能动手，要让他先动手、再慢慢懂。**

具体来说：

1. **最大的标题看不懂没关系，但解释它的例子必须放在它旁边。** 现在「把『如果』改成『你』」这个大标题的意思，躲在右上角的小卡片里，新人找不到答案。把例子挪到标题下面，一眼就能看懂「哦，原来是给我一个人定制的讲义」。

2. **四个入口只突出一个最重要的。** 现在「学生、老师、评委、上传文章」四张卡片一样大，新人不知道点哪个。既然学生是主要用户，就把「我是学生」做成最醒目的大按钮，其余三个做小一点、放旁边。

3. **底部那三条「原则」别全堆在首屏。** 它们是给已经感兴趣的人看的细节，不是给第一次来的人看的。收到第二屏或者点开再看的折叠区里。

4. **「同学A/同学B」示例放在大按钮正下方**，配一句话：「先看看示例：同学A和你一样不认识 fret」。这样不敢直接开始的人，可以先看看别人拿到的成品长什么样，心里踏实了再开始。

5. **CTA 就是那个「现在点这里」的主按钮。** 一页只留一个最显眼的，用户才不会纠结。

## 二、专业表述版

**核心设计策略：将概念解释后置、首次行动前置，通过视觉层级强制建立预期的浏览动线（reading flow），并以最小行动闭环（minimum action loop）达成 aha-moment 前置。**

具体要点：

1. **信息架构（IA）**：遵循格式塔邻近性原则，将核心示例（fret 案例）与标题重组为同一语义单元，形成「主张 → 证据」的认知闭环，消除当前的视线跳跃。

2. **视觉层级与希克定律（Hick's Law）**：主 CTA「我是学生」独占最高视觉权重（实心填充、强调色），其余三个角色入口降级为次级操作；同时修正「上传文章」与前三个角色入口的分类学错误（taxonomy error），避免心智模型冲突。

3. **渐进披露（Progressive Disclosure）**：产品理念（原文不改 / 卡点搭梯子 / 班级热力图）移出首屏，收纳入折叠区或第二屏，降低首屏认知负荷（cognitive load）。

4. **演示画像的定位**：不作为独立导航项，而是主 CTA 的**低风险替代路径（zero-commitment trial）**，锚定主按钮下方，以「同侪情境（peer context）」文案降低启动门槛；展示层采用就地展开（inline expansion），不打断用户流向主流程。

5. **CTA（Call To Action）**：全页唯一主行动号召，动词开头文案、最高视觉权重，其余操作按优先级递减处理，消除决策瘫痪（choice paralysis）。
