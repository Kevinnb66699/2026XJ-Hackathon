# 知适 设计规范（前端实现以此为准）

设计稿（Design 画布，7 屏）：https://claude.ai/artifact/FqRSXL3MfGxsnwXSj7d1w1

- **学生端**：问卷 → 粗读 → 学生词 → 精读（读懂梯子）→ 写作（表达链）
- **其他**：老师端、评委模式（展位）

## 基调

- 纸面灰底，白色卡片，深墨绿表示「可以点」，琥珀表示「卡点和高亮」。
- 不用渐变、emoji、左侧色条卡片。
- 不引用任何外部字体或 CDN（国内网络）。

## 字体

- **英文原文**（阅读区）：`Georgia, 'Times New Roman', 'Songti SC', serif`。手机 19px，行高 1.75；老师端 17px，行高 2。
- **界面**：`-apple-system, BlinkMacSystemFont, 'PingFang SC', 'Microsoft YaHei', 'Segoe UI', sans-serif`。
- **字号**：标题 18–24px，正文 14–16px，说明 12–13px。

## 组件

- **顶栏**：高 56px，白底，有返回键、标题和副标题，右侧是「表达本 N」胶囊按钮。
- **步骤条**：问卷 · 粗读 · 学生词 · 精读 · 写作 · 反馈。当前步骤用主色加粗下划线。
- **卡片**：圆角 14px，1px 边框；焦点卡用 1.5px 主色边框。
- **按钮**：主按钮为主色底白字，圆角 12–14px，高 46–50px；次按钮为白底加边框；可点区域不小于 44px。
- **胶囊标签**（打卡句、老师要求、定向、随机等）：圆角 999px，12px 字，浅底配深字。
- **注释词**：琥珀色 2px 点状下划线，点开后「先猜后看」：二选一 → 显示中文（有老师英文释义时一并显示）。
- **粗读点词**：琥珀浅底加 2px 虚线下划线。
- **读懂梯子**：三级列表（编号圆点、标题、已打开或锁定图标）。打卡句交初稿前，第 2、3 级显示锁图标。
- **「给你」便签**：引用学生自己的行为和老师讲义原话，不写等级。
- **图标**：内联描边 SVG，线宽 2。

## 文案原则

- 学生端不出现语法术语。梯子 L1 的标签写「谁 / 做了什么」。
- 写作反馈只说「用得对 / 再看看原文」，并引用原文例句，**不给出改写后的句子**。
- 老师端可以显示结构名称（同位语从句、倒装等）。示例数据必须标明「示例数据」。
